# Correlation Analysis & Heatmap Dashboard

## Project Overview

This project focuses on analyzing relationships between different business variables using correlation analysis and visualization.

The project follows a simple Data Analyst workflow:

*Excel → Python → Tableau*

## Tools Used

* *Microsoft Excel* – Data cleaning and preparation
* *Python (Pandas, NumPy)* – Correlation analysis and statistical analysis
* *Tableau* – Data visualization and dashboard creation

## Data Cleaning

The raw dataset was cleaned and prepared using *Microsoft Excel*.

The cleaning process included:

* Checking missing values
* Removing duplicate records
* Cleaning unnecessary spaces
* Checking data consistency
* Preparing the final dataset for analysis

## Python Analysis

The cleaned dataset was analyzed using Python and Pandas.

Key analysis included:

* Dataset validation
* Statistical summary
* Numeric variable selection
* Correlation matrix
* Identification of strong positive and negative relationships
* Revenue and Profit correlation analysis

## Tableau Dashboard

The cleaned dataset was imported into Tableau to create visualizations for understanding relationships between variables.

The dashboard includes relationship analysis between:

* Marketing Spend and Revenue
* Website Visits and Revenue
* Orders and Revenue
* Orders and Profit
* Marketing Spend and Profit

## Key Objective

The main objective of this project is to understand how different business variables are related and identify the strongest relationships that may be useful for business decision-making.

## Conclusion

Correlation analysis helps identify the strength and direction of relationships between variables. The Tableau dashboard provides an easy-to-understand visual representation of these relationships.
